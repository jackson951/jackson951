## About me

I build business software end to end: I gather the requirements, design the architecture and data model, write the API and the UI, deploy it, and support it once people depend on it.

Most of my work sits where business processes meet security. That means signing users in with Microsoft Entra ID, deciding what each role can see and do, routing requests through multi-step approvals, and keeping an audit trail of who did what.

## How I work

- **Start with the problem.** I talk to the people who will use the system before I design anything.
- **Secure by default.** Authentication, authorization and input validation go in from the first commit.
- **Keep it readable.** Clear module boundaries, typed contracts and documented APIs.
- **Own it in production.** Logging, monitoring and fast, calm fixes when something breaks.
