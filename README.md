## 👋 About me

I build business software end to end: I gather requirements, design the data model and API, build the UI, deploy it, and support it once people depend on it.

Most of my work sits where **business processes meet security**: signing users in, deciding what each role can see and do, routing requests through approvals, and keeping an audit trail of who did what. Lately I've been adding **AI** to that mix, building with Claude Code and the Claude API.

## 🧭 How I work

- **Start with the problem.** I talk to the people who will use the system before I design anything.
- **Secure by default.** Authentication, authorization and input validation go in from the first commit.
- **Keep it readable.** Clear module boundaries, typed contracts and documented APIs.
- **Own it in production.** Good logging, and calm, fast fixes when something breaks.
